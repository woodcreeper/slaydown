# A little room to read

## The plan

SlayDown is a public product demo built around ordinary Markdown files, giving people a calm place to preview their work and follow the outline without leaving their local editor.

> Make the writing feel simple, immediate, and inviting.

## The next iteration

Add fast search and a small set of reading styles, while keeping automatic refresh reliable as the document changes.

## Three small steps

| Step | Experience | Result |
| --- | --- | --- |
| Preview | Open the current Markdown file | See a polished reading view |
| Explore | Browse the outline and search | Move through the document quickly |
| Edit | Return to the local editor | Watch automatic refresh reflect each save |
